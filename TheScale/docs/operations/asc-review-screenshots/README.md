# ASC subscription Review Information screenshots

Upload **one** paywall PNG to each Coach SKU (Plus/Pro × Annual/Monthly).

## File to upload

`subscription-review-paywall-annual.png` (this folder)

Shows Unlock Coach with **Annual** selected and Free / Plus / Pro tiers + prices.

## Regenerate

```bash
./TheScale/scripts/capture-asc-subscription-review.sh
```

## ASC steps

1. App Store Connect → FATNAG → Monetization → Subscriptions → **Coach**
2. Open each subscription → **Review Information**
3. Screenshot → Choose File → select `subscription-review-paywall-annual.png`
4. Review Notes → paste from the ASC StoreKit setup canvas (§5b)
5. Save

Skip the optional 1024×1024 Image field unless you enable App Store Promotion / win-back later.
