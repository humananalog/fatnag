# Promo screenshots

Generated by `scripts/capture-promo-shots.sh` from the iOS Simulator using Bob / Alice demo personas.

| File | Surface | Launch |
|------|---------|--------|
| `01-home.png` | Weigh tab / Horizon gauges | `-promoShot=home` |
| `02-weigh.png` | Settled live weigh sheet | `-promoShot=weigh` |
| `03-progress.png` | Progress charts | `-promoShot=progress` |
| `04-keel.png` | Keel chat | `-promoShot=keel` |

Persona folders: `bob/` and `alice/`. Root copies default to **Bob** for the marketing site.

```bash
./sites/fatnag-com/scripts/capture-promo-shots.sh
./sites/fatnag-com/scripts/capture-promo-shots.sh --record   # also writes recordings/*.mp4
```
